genSound Color Lab

View source on GitHub ↗

genSound maps selected audio features across a track into one image. Change the color rules and layout to compare the results.

The lab samples 250,000 overlapping windows across a track. Each window is 100 milliseconds long and becomes one colored point. It estimates pitch, measures signal level, and finds a peak frequency. The default uses estimated note groups for hue, relative signal level for saturation, and relative peak frequency for lightness. Windows below the level threshold, or without a pitch estimate, appear black. Both layouts use the same analysis. Rings place the opening near the center and later windows farther out. The Hilbert layout follows a continuous path through the image. Change the palette or mapping rules while keeping the track fixed to compare the results. The values are scaled within each recording, so the colors show relative differences within a track. The pitch values are estimates. The image represents selected features rather than a transcription of every note.
